The Reclaim Group

Memory-Safe Visual Software Engine

The Reclaim Group OÜ develops a Rust-based visual software development environment and engine for building reliable, memory-safe software.

Join the Alpha Test - Contact us at info@reclaim.ee

Rust Architecture

Engineered in Rust with a Data-Oriented Design (DOD) and Entity Component System (ECS) core, ensuring memory safety and deterministic performance for safety-critical and legacy modernization projects.

Visual Programming

Powered by a custom GPU-accelerated 2D/3D rendering pipeline (wgpu & WGSL) that turns complex systems logic into an intuitive, real-time visual block and node editor.

Community Ecosystem

Built on a modular plugin architecture where developers and the community can create, share, and hot-swap custom themes and editor extensions.
